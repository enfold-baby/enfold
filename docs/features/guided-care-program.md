# Guided Care Program

## Goal

Provide calm, doctor-reviewed, age-aware guidance without turning the app into a diagnostic product.

## Content Model

- English now. Romanian later (device RO → RO, else EN, Settings override) — see `feature/todos/I18N_RO.md`.
- Reviewer attribution internally; public text can say it is medically reviewed by the Enfold medical team.
- Versioned content so updates can be audited.

## MVP Topics

- Newborn feeding basics.
- Safe sleep.
- Diaper expectations.
- When to contact a doctor.
- Common appointment preparation.

## Safety Boundary

Guidance should use escalation wording such as "contact your doctor" or "seek emergency care" for red flags. It must avoid individualized diagnosis or treatment instructions.
