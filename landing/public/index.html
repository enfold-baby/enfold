Every line of Enfold is public.

A baby app holds your family’s most private notes. “No ads, no selling data” is easy to say. So we put the whole thing on GitHub under the AGPL: the app, the API, this website, and every learn card with the name of the clinician who reviewed it. Read it, run it, fork it, help translate it.
