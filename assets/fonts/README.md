# BloomDue fonts

BloomDue bundles the following Google Fonts so typography works offline and
renders consistently in tests and release builds:

- Nunito: Regular, SemiBold, Bold, ExtraBold, Black
- Fraunces: SemiBold, Bold

Both families are distributed under the SIL Open Font License. The license
texts are included beside the font files as `OFL-Nunito.txt` and
`OFL-Fraunces.txt`.
